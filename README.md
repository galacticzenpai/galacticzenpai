### 🚀 Flagship Engineering Cockpits

#### 1. ⚡ ClockEE — Autonomous JEE Tactical Cockpit & Cognitive CBT Engine
<p align="center">
  <a href="https://galacticzenpai.github.io/ClockEE/">
    <img src="https://raw.githubusercontent.com/galacticzenpai/ClockEE/main/screenshots/02_command_center.png" alt="ClockEE Cockpit Preview" width="96%" style="border-radius: 12px; border: 1px solid rgba(0,242,254,0.3); box-shadow: 0 10px 30px rgba(0,0,0,0.5);" />
  </a>
</p>

*The world's first drift-free study operating system equipped with real-time biometric eye-tracking mascot, sub-second latency autopsies, and adaptive CBT examination simulation.*

* **⏱️ Sub-Second Tactical Pacing**: Per-question lap timer telemetry, latency delta calculations, and real-time JEE (+4/-1) projected mark calculations.
* **📝 Crash-Proof NTA CBT Engine**: Exact JEE computer-based exam simulator with LaTeX MathJax formula rendering, responsive question palettes, and state recovery.
* **🐻 Interactive Biometric Mascot**: Whimsical Cyber-Bear with cursor gaze tracking, procedural nose-boop blush, and reactive eye-covering paws on password input.
* **☁️ Multi-User Sandbox Isolation**: Independent zero-leak local and cloud profile slots with Firebase Realtime Database backing.
